# Proyecto vanilla

Página básica con HTML, CSS y JavaScript, sin dependencias ni compilación.

## Ver la página

Abre `index.html` directamente en tu navegador.

## Archivos

- `index.html`: estructura de la página.
- `styles.css`: estilos básicos y adaptables a móviles.
- `main.js`: interacción del botón.

## Próximas iteraciones

Agregar pruebas con el módulo nativo `node:test`, integración continua con GitHub Actions y despliegue en GitHub Pages.
